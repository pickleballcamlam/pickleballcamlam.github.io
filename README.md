# camlampickleball.dpdns.org

Trang đăng ký cặp đấu công khai của Cộng Đồng Pickleball Cam Lâm.
Bản tĩnh (static) của demo `demo-trang-dang-ky-cap-dau` — giao diện y hệt app diễn đàn.
Đăng ký trên trang chỉ là mô phỏng trong trang (không ghi vào app thật);
luồng đăng ký thật đi qua Google Form rồi nhập vào app diễn đàn theo đợt.
